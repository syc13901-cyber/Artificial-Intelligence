# 实验 2：Iris 数据集的 KNN 与决策树分类（第二次实验，2026-10-03）

## 实验内容

在鸢尾花数据集（150 样本、4 特征、3 类）上比较 KNN 与决策树：

1. 数据划分：70% 训练 / 30% 测试，`random_state=42`，`stratify=y` 保证类别均衡；
2. KNN 的 k 值对比（k = 1, 3, 5, 7, 9, 11）；
3. 决策树最大深度对比（depth = 1, 2, 3, 5, None），观察过拟合（训练集 100% 而测试集下降）；
4. 标准化（StandardScaler）对 KNN 的影响；
5. 单次划分 vs 5 折交叉验证的准确率与标准差对比；
6. 不同 `random_state` 下准确率的敏感性；
7. 取两个特征绘制 k=1/5/11 的 KNN 决策边界图。

## 关键结果

- KNN 单次划分：k=5 最佳，测试准确率 **0.9778**；
- 决策树：depth=3 达到 0.9778，depth≥5 时训练集 100%、测试集降到 0.9333（过拟合）；
- 5 折交叉验证下 k=7 与 k=11 平均准确率 0.980，比单次划分更稳定。
